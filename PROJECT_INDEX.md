## Status Flags

| Status | Meaning |
|---|---|
| Planned | Project is designed but not started publicly |
| In progress | Project is actively being built |
| Needs review | Project is built but needs final public-safety/documentation review |
| Published | Project is public and linked from this hub |

## Publication Rules

Before linking a project publicly:

- README is complete
- no private data is included
- `.env` is not committed
- sample data is safe
- screenshots contain no private information
- assumptions and limitations are documented
- project retrospective is complete
- project can be explained in an interview

## How to Add a Published Project Link

When a project is published, update the row from:

```markdown
| 1 | SaaS Support Intelligence Dashboard | Published | View repo | SQL Server, Power BI, Power Query, SLA analysis | Must build |
```

to:

```markdown
| 1 | SaaS Support Intelligence Dashboard | Published | [View repo](https://github.com/YOUR-USERNAME/saas-support-intelligence-dashboard) | SQL Server, Power BI, Power Query, SLA analysis | Must build |
```

Also update the project table in `README.md`.
