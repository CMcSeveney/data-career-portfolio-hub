# Portfolio Strategy

The portfolio is designed to show practical progression from data analysis into technical SaaS support, data engineering, machine learning and AI systems.

## Strategy

The projects are selected to demonstrate business understanding, technical troubleshooting, SQL and data validation, dashboard communication, Python automation, API investigation, ETL and warehouse design, model evaluation, AI safety and workplace stack awareness.

## Target Roles

- Data Analyst
- BI Analyst
- Technical Data Analyst
- Technical Application Support Engineer
- SaaS Support Engineer
- Data Operations Engineer
- Analytics Engineer
- Junior Data Engineer
- AI/data systems roles longer term

## Differentiation

This portfolio is designed around support, operations and real-world data problems rather than only overused beginner datasets.
