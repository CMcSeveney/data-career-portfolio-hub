## Repository README Standards

Each public project README should include business problem, tools used, dataset/source, repository structure, workflow, screenshots, results, limitations, future improvements and interview talking points.

## Linking Project Repositories

When a project is published:

1. Copy the public repo URL.
2. Update the project row in `README.md`.
3. Update the same project row in `PROJECT_INDEX.md`.
4. Change the status to `Published`.
5. Commit with a clear message.

Example commit message:

```text
Update hub with published SaaS dashboard project
```
