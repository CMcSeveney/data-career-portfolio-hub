# Data Career Portfolio Hub

This repository is the public landing page for my data and technical portfolio.

It documents my progression from data analysis into technical SaaS support, data engineering, machine learning and AI/data systems. The projects are designed around realistic business and support scenarios rather than generic beginner examples.

## Portfolio Focus

- SQL Server / T-SQL
- SQL Server Management Studio (SSMS)
- Power BI and Power Query
- Python and pandas
- REST APIs, JSON, Postman and Bruno
- ETL pipelines and data validation
- Data warehousing and dimensional modelling
- Machine learning model evaluation
- PySpark and Databricks
- FastAPI and AI/NLP support tooling
- GitHub documentation and project presentation
- Workplace stack awareness: .NET, ASP.NET Core, Azure SQL, Azure Functions, Azure Pipelines, Docker and structured logging

## Privacy and Data Safety

All public projects use public, sample or synthetic data only.

No employer data, customer data, private logs, internal screenshots, API keys, passwords or work ticket references are included.
